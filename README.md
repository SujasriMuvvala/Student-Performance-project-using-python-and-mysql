# Student-Performance-project-using-python-and-mysql

## Overview
The Student Performance Prediction and Analytics Platform is a Python and MySQL based data analytics project developed to analyze and predict student academic performance.

This system stores student-related data such as attendance, study hours, assignment scores, and internal marks in a MySQL database. Using Python, the project performs data analysis, visualization, and machine learning-based prediction to identify student performance trends and academically at-risk students.

The project demonstrates practical implementation of:
- Database Management
- Data Analytics
- Data Visualization
- Machine Learning
- Python-MySQL Integration

---

# Features

- Student data storage using MySQL
- Data retrieval using Python
- Academic performance analysis
- Average marks calculation
- Top-performing student identification
- Low-attendance student detection
- Data visualization using graphs
- Machine Learning based pass/fail prediction
